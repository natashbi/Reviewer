Iba dapat ang pangalan at IP ng bawat client. Pareho ang DNS: 192.168.10.10.

Kung may error

“An Active Directory Domain Controller (AD DC) for the domain could not be contacted”

I-check na 192.168.10.10 ang Preferred DNS ng client, at parehong intnet ang network ng server at client.

Walang “Reply from” sa ping

I-off ang firewall sa server at sa client. I-check ang IP ng dalawa sa ncpa.cpl.

“The user name or password is incorrect” sa pag-join

I-type bilang KTG\kindson, at i-check ang Caps Lock.

May error na duplicate name o IP sa client 2

Gamitin ang Win11Client2 at 192.168.10.21, hindi ang kapareho ng client 1.

Walang 64-bit na Windows sa Version

Sabihan ang teacher o lab in-charge. Naka-disable ang virtualization sa BIOS.

“This PC can’t run Windows 11”

Gawing 4096 MB ang Base Memory, at siguraduhing Windows 11 (64-bit) ang Version.

Ayaw gumana ng Ctrl + Alt + Del

Pindutin ang Right Ctrl + Delete, o Input → Keyboard → Insert Ctrl-Alt-Del sa menu ng VM window.
